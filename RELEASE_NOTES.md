## Ancrage 1.0.0 : première version

Planifiez vos révisions avec la méthode des J : chaque chapitre revient à J+1, J+3, J+7… juste avant de l'oublier. Application 100 % locale, sans compte ni connexion.

### Points clés

- **Révisions du jour** : passages en retard, à faire et déjà faits, progression de la journée et série de jours.
- **Méthode des J** : rythmes Classique (J+1, J+3, J+7, J+14, J+30), Intensif, Long terme ou personnalisé.
- **Ressenti à chaque passage** : « À revoir » (demain), « Correct » (rythme prévu), « Acquis » (intervalle allongé de 50 %).
- **Planning mensuel** avec alerte des journées trop chargées.
- **Matières** avec couleur, icône, date d'examen, compte à rebours et nombre de chapitres revus à temps.
- **Bilan** : activité sur 20 semaines, taux de « À revoir », avancement par matière.
- Annulation de chaque action, export / import JSON, thème clair ou sombre.

### Quel fichier télécharger ?

| Fichier | Pour qui ? |
|---|---|
| `Ancrage-Setup-1.0.0.exe` | Windows : installateur classique (recommandé). |
| `Ancrage-1.0.0-portable.exe` | Windows : version portable, sans installation (clé USB, poste sans droits admin). |
| `Ancrage-1.0.0-linux-x86_64.AppImage` | Linux, toutes distributions : `chmod +x` puis lancer. |
| `Ancrage-1.0.0-linux-amd64.deb` | Debian, Ubuntu, Mint : `sudo apt install ./Ancrage-1.0.0-linux-amd64.deb` |

> Windows peut afficher un avertissement SmartScreen car l'exécutable n'est pas signé : « Informations complémentaires » puis « Exécuter quand même ».
